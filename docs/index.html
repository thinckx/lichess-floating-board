Floating Board for Lichess

Your game stays on top of your work.

A Chrome and Edge extension that puts the board and clocks of your ongoing Lichess game in a small window above every other app. Make your move without leaving what you're doing.

Four moves to set it up

  1. 1.Open your game

    Start or continue a game you are playing on lichess.org.

  2. 2.Click Float board

    The button sits at the bottom right of the game page. Or press Alt+P.

  3. 3.Get back to work

    The board, clocks and names stay on top of every app. Click or drag to move, just like on Lichess.

  4. 4.Close it when you're done

    Everything returns to the Lichess tab, and the game carries on there.

Fair play

It only changes where the board is shown. No engine, no analysis, no move suggestions. Lichess itself keeps running the game.

No data collected

Nothing is tracked or sent anywhere. The only thing saved is the size of the floating window, on your own device. Read the privacy policy.

Open source

The full code is on GitHub under the MIT license, so you can check every line or help improve it.

Install it today

  1. Download or clone the GitHub repository.
  2. Open chrome://extensions and switch on Developer mode.
  3. Click Load unpacked and choose the downloaded folder.

Needs Chrome or Edge 116 or newer on desktop.
